# Kanban AI — Archetypes

Este repositório publica os **archetypes** (backend, frontend, site) usados pelo Kanban AI como templates de projeto. Cada archetype é distribuído como um arquivo `.zip` anexado à release `latest` do GitHub, atualizada automaticamente a cada push na branch `main`.

---

## 1. Baixe os ZIPs

Os arquivos ficam disponíveis na release `latest` deste repositório:

👉 [**Releases — latest**](https://github.com/kanban-ai/kanban-archetype/releases/latest)

Anexos disponíveis:

* `backend.zip`
* `frontend.zip`
* `site.zip`

Baixe apenas os archetypes que pretende cadastrar/atualizar.

---

## 2. Configure no Kanban AI

Acesse a área administrativa de archetypes (necessário estar autenticado como **administrador**):

👉 [https://kanban.devmania.ai/admin/archetypes](https://kanban.devmania.ai/admin/archetypes)

Nessa tela você pode:

* **Criar um novo archetype** — informe nome/identificador e faça o upload do `.zip` correspondente.
* **Atualizar um archetype existente** — abra o registro desejado e substitua o `.zip` pela versão recém-baixada.

Após salvar, o archetype fica disponível para ser selecionado ao criar novos projetos no Kanban AI.

---

## 3. Atualizações futuras

A release `latest` é sempre o build mais recente da branch `main`. Sempre que houver alterações nos archetypes, basta repetir o passo 1 (baixar) e o passo 2 (atualizar o registro existente no admin).
